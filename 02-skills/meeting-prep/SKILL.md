# Meeting prep

Given a meeting (by title, time or the name of a company), find the attendees, pull the recent history with each one, and write a one-page prep note.

## Steps

1. Find the meeting on the calendar. If more than one matches, list them with times and stop to ask which one. Record the title, the time, the attendees and the agenda text if there is one.
2. For each attendee who is not on our own domain, search mail for the last five threads with that person, newest first, going back no more than 90 days. Read each thread, not just the subject line.
3. For each attendee's company, search mail once more by company name in case other people there have written in.
4. If a merchant folder, a contract or a notice about the company exists in the working folder, read it. Do not search outside the working folder and the mailbox.
5. Write `prep-<company>-YYYY-MM-DD.md` with four sections:
   - **Who**: each external attendee, title, company, and the date of the last message either way.
   - **Open threads**: one line per unresolved thread: subject, date, who owes the next message, what they asked for. Oldest first.
   - **Numbers**: any dollar figure, rate, volume, date or deadline that appears in those threads, each with the thread it came from. Exactly as written in the source.
   - **Three things to raise**: the three items with the most money or the nearest deadline attached, each one a single sentence that ends with the question to ask.

## Rules

- Quote dates, amounts and names exactly as they appear in the source. Never infer a figure that is not written down.
- "Who owes the next message" is a fact from the thread, not a judgment. If the last message is from them and asks a question, we owe it.
- Keep the note to one page. If there are more than three open threads, the oldest three go in full and the rest are one line each.
- If an attendee has no mail history, say so in **Who** and do not invent context.
- Do not send anything, create events or edit the calendar. Reading only.
